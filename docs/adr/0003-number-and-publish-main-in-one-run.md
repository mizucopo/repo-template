# Number and publish main in one Actions run

Normal read-only CI precedes squash merge. One serialized release run uses only the latest PR merged on main to number current main, atomically pushes main version metadata and the same commit's tag with GITHUB_TOKEN, then builds, validates and publishes that commit. Earlier unpublished PR classifications are neither aggregated nor required. The PR is identified by main ancestry and its merge event, not its creation time; unmerged PRs and numbering commits are excluded. Release commit trailers record the selected PR and identify reruns; without a new merged PR, no new number is allocated. Dedicated merge preparation, CI admission, App authentication, bootstrap and dependency auto-classification are removed. Destination settings must permit direct main/tag pushes. Existing published objects remain immutable.
